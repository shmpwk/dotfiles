# dotfiles

Run `install.py` to link configs and run install scripts.

## Caps Lock: US English / Mozc Japanese

After `ibus-mozc` is installed, Caps Lock toggles between English (US) and Mozc.

Applied by `install_scripts/setup-caps-ime-toggle.sh` (`grp:caps_toggle`).

Equivalent in GNOME Tweaks:

1. Keyboard & Mouse → Additional Layout Options
2. Switching to another layout → Caps Lock
